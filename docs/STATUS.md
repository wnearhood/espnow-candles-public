## Safety

- These run on batteries inside something that looks like a candle. Check
  your wiring with a meter before inserting batteries.
- Never connect USB with batteries installed (remove JP1 first; see the
  [schematic](schematic.svg)).
- Battery sensing is wired for 2×AA NiMH. Other packs need a voltage divider.
